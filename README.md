## 01 / About

I'm a **Data Engineer** working across **ETL/ELT pipelines, enterprise data integration, data modeling, and quality engineering**. My background includes SQL, Python, PySpark, Databricks, Snowflake, dbt, and Azure, alongside Data Warehousing, Medallion Architecture, governance, and CI/CD.

My personal portfolio explores real engineering questions through **beauty, K-beauty, fashion, and entertainment**. Every project aims to show not only the tools, but the design decisions, data limitations, and verification steps behind the result.

### 01 — [Beauty Commerce Intelligence](https://github.com/MariMecucci/beauty-commerce-intelligence)

**Data Engineering · Analytical AI · Data Quality**

A local-first platform for a **fictional beauty retailer**, using reproducible synthetic data, Bronze/Silver/Gold transformations, validated Parquet datasets, a Streamlit dashboard, and an AI agent restricted to approved analytical tools.

`Python` · `SQL` · `DuckDB` · `Parquet` · `GitHub Actions` · `Streamlit` · `LangGraph`
